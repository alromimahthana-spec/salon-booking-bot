# 💅 بوت صالون تجميل - Salon Booking Bot

بوت يحجز مواعيد صالونات التجميل تلقائياً!

### ايش يسوي؟
- يعرض خدمات الصالون وأسعارها
- يحجز موعد للزبونة (اسم + رقم + تاريخ + وقت)
- يطلع فاتورة حجز جاهزة
- يرسل تذكير للزبونة قبل موعدها

### مناسب لـ:
صالونات اليمن 🇾🇪 والسعودية 🇸🇦 والخليج

### السعر:
3000 ريال سعودي
